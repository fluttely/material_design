# Estrutura da Biblioteca Material Design

## Visão Geral da Arquitetura

```
lib/
├── src/
│   ├── design/              # Especificações M3 (m3.material.io)
│   │   ├── sys/            # Design System - Fundações
│   │   ├── ref/            # Reference - Tokens de referência
│   │   └── comp/           # Components - Especificações de componentes
│   │
│   ├── toolkit/            # Implementações práticas (material.dart)
│   │   ├── widgets/        # Widgets customizados
│   │   ├── builders/       # Widget builders
│   │   └── painters/       # Custom painters
│   │
│   └── helpers/            # Utilitários e extensões
│       ├── utils/          # Funções utilitárias
│       ├── extensions/     # Extensões Dart
│       └── converters/     # Conversores entre design e toolkit
│
├── material_design.dart    # Arquivo principal de exportação
└── pubspec.yaml
```

## Exemplo de Uso

```dart
import 'package:material_design/material_design.dart';

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    // Usando o design system
    final colorScheme = M3ColorScheme.fromSeed(
      seedColor: Colors.blue,
      brightness: Brightness.light,
    );

    // Usando specs do design
    final elevationLevel = ElevationLevels.level2;
    final typeScale = TypeScale.bodyLarge;

    // Usando widgets do toolkit
    return M3Card(
      elevation: elevationLevel,
      child: M3ElevatedButton(
        onPressed: () {},
        child: Text('Click me'),
      ),
    );
  }
}
```

## Benefícios desta Estrutura

1. **Separação Clara**: Design specs (M3) vs Implementação (Flutter)
2. **Modularidade**: Cada parte pode evoluir independentemente
3. **Reutilização**: Helpers e utils podem ser usados em toda a lib
4. **Manutenibilidade**: Fácil de encontrar e atualizar componentes
5. **Escalabilidade**: Fácil adicionar novos componentes ou sistemas
6. **Type Safety**: Uso forte de tipos Dart para prevenir erros
7. **Documentação**: Estrutura auto-documentada pela organização
