# Fundamentos

Os fundamentos do M3 (https://m3.material.io/foundations) são as regras transversais
que todo estilo e componente obedece. Neste pacote, eles se mapeiam em quatro áreas:

| Fundamento M3 | Nota | Módulos do pacote |
| :--- | :--- | :--- |
| Design tokens | [[Design Tokens]] | `tokens` (o contrato em si) |
| Acessibilidade | [[Accessibility|Acessibilidade]] | `adaptive` (`M3Accessibility`), `color` (utilitários WCAG), `interaction` (anel de foco) |
| Design adaptativo / Layout | [[Adaptive Design|Design Adaptativo]] | `adaptive`, `tokens` (breakpoints, margens, larguras de layout) |
| Estados de interação | [[Interaction States|Estados de Interação]] | `interaction`, `tokens` (opacidades de state layer) |

Content design e outros fundamentos não relacionados a código (estilo de escrita,
diretrizes de iconografia) estão fora do escopo de um pacote de tokens e
intencionalmente não têm notas aqui.
