## 🏗 Elevation Token System

A comprehensive elevation management system following Material Design 3 specifications with token-based architecture.

### Key Features

- **Token hierarchy**: Reference → System → Component tokens
- **State management**: Built-in support for hover/pressed/dragged states
- **Theme integration**: Works seamlessly with Flutter's theming system
- **Type safety**: Strongly typed tokens
- **Self-documenting**: Each token contains metadata and descriptions

### Basic Usage

#### Applying Elevation

```dart
ElevatedSurface(
  elevationToken: CardElevationTokens.elevated,
  child: CardContent(),
);
```

#### Handling States

```dart
final elevation = MaterialElevation.getStateElevation(
  idle: ButtonElevationTokens.elevated,
  hover: ButtonElevationTokens.elevatedHover,
  pressed: ButtonElevationTokens.elevatedPressed,
  isHovered: isHovered,
  isPressed: isPressed,
);
```

### Token Hierarchy

#### Tracing Token Origins

```dart
final token = CardElevationTokens.elevated;
final hierarchy = token.getTokenHierarchy();
// Returns: [ComponentToken, SystemToken, ReferenceToken]
```

#### Centralized Management

```dart
// Change propagates throughout the system
static const dp1 = ReferenceToken<double>(
  2.0,  // Single source of truth
  'elevation.dp1',
);
```

### Self-Documenting Tokens

```dart
static final elevatedHover = ComponentToken<double>.fromSystem(
  ElevationSystemTokens.level2,
  component: 'Button',
  tokenName: 'elevation',
```

### Complete Example

```dart
class StatefulCard extends StatefulWidget {
  @override
  _StatefulCardState createState() => _StatefulCardState();
}

class _StatefulCardState extends State<StatefulCard> {
  bool _isHovered = false;
  bool _isDragged = false;

  @override
  Widget build(BuildContext context) {
    final elevationToken = _isDragged
        ? CardElevationTokens.elevatedDragged
        : _isHovered
            ? CardElevationTokens.elevatedHover
            : CardElevationTokens.elevated;

    return MouseRegion(
      onEnter: (_) => setState(() => _isHovered = true),
      onExit: (_) => setState(() => _isHovered = false),
      child: GestureDetector(
        onPanStart: (_) => setState(() => _isDragged = true),
        onPanEnd: (_) => setState(() => _isDragged = false),
        child: AnimatedContainer(
          duration: const Duration(milliseconds: 200),
          child: ElevatedSurface(
            elevationToken: elevationToken,
            child: Content(),
          ),
        ),
      ),
    );
  }
}
```

5. **Documentation**: Built-in token descriptions
6. **Alignment**: Fully compliant with Material Design 3

### Theme Integration

```dart
@immutable
class ElevationTheme extends ThemeExtension<ElevationTheme> {
  final DesignToken<double> cardElevation;
  final DesignToken<double> buttonElevation;

  const ElevationTheme({
    required this.cardElevation,
    required this.buttonElevation,
  });

  factory ElevationTheme.material3() {
    return ElevationTheme(
      cardElevation: CardElevationTokens.elevated,
      buttonElevation: ButtonElevationTokens.elevated,
    );
  }
}
```
