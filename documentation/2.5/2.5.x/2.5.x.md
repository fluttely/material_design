## 🎯 Principais Mudanças

### 1. **Hierarquia Completa de Tokens**
- **Reference Tokens**: Valores brutos (dp0, dp1, dp3, etc.)
- **System Tokens**: Níveis semânticos (level0-5)
- **Component Tokens**: Valores específicos por componente

### 2. **Organização Profissional**
```dart
// Antes: Valores hardcoded
static const double level1 = 1.0;

// Agora: Token hierárquico
static final level1 = SystemToken<double>.fromReference(
  ElevationReferenceTokens.dp1,
  systemName: 'elevation.level1',
  description: 'Level 1: Low elevation for cards and buttons',
);
```

class _CustomCardState extends State<CustomCard> {
  bool _isHovered = false;
  bool _isDragged = false;

  @override
  Widget build(BuildContext context) {
    // Obtém o token de elevação baseado no estado
    final elevationToken = _isDragged
        ? CardElevationTokens.elevatedDragged
        : _isHovered
            ? CardElevationTokens.elevatedHover
            : CardElevationTokens.elevated;

    return MouseRegion(
      onEnter: (_) => setState(() => _isHovered = true),
      onExit: (_) => setState(() => _isHovered = false),
      child: GestureDetector(
        onPanStart: (_) => setState(() => _isDragged = true),
        onPanEnd: (_) => setState(() => _isDragged = false),
        child: AnimatedContainer(
          duration: const Duration(milliseconds: 200),
          child: ElevatedSurface(
            elevationToken: elevationToken,
            borderRadius: BorderRadius.circular(12),
            padding: const EdgeInsets.all(16),
            child: Content(),
          ),
        ),
      ),
    );
  }
}

### 8. **Vantagens do Sistema de Tokens**

1. **Single Source of Truth**: Valores definidos uma vez
2. **Type Safety**: Tokens fortemente tipados
3. **Hierarquia Clara**: Reference → System → Component
4. **Flexibilidade**: Fácil override por componente/estado
5. **Documentação Viva**: Descrições nos próprios tokens
6. **Testabilidade**: Fácil validar tokens contra specs M3

@immutable
class ElevationTheme extends ThemeExtension<ElevationTheme> {
  final DesignToken<double> cardElevation;
  final DesignToken<double> buttonElevation;
  
  const ElevationTheme({
    required this.cardElevation,
    required this.buttonElevation,
  });
  
  factory ElevationTheme.material3() {
    return ElevationTheme(
      cardElevation: CardElevationTokens.elevated,
      buttonElevation: ButtonElevationTokens.elevated,
    );
  }
  
  // Permite override customizado mantendo a estrutura
  factory ElevationTheme.custom() {
    return ElevationTheme(
      cardElevation: ComponentToken<double>(
        2.0,
        'custom.card.elevation',
        component: 'Card',
        description: 'Custom card elevation',
      ),
      buttonElevation: ButtonElevationTokens.elevated, // Mantém o padrão
    );
  }
}
