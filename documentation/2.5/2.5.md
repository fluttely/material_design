Aqui está a implementação completa do sistema de elevação do Material Design 3:Implementei o sistema completo de elevação do Material Design 3 com todos os recursos solicitados:

## 🎯 Recursos Implementados

### 1. **MaterialElevation** - Níveis 0-5
- Valores exatos em dp para cada nível
- Documentação dos casos de uso para cada elevação
- Método helper `getElevation(level)`

### 2. **MaterialShadows** - Shadow Values Específicos
- Duas camadas de sombra por nível (mais realista)
- Valores exatos de offset, blur, spread e opacidade
- Método `withColor()` para sombras customizadas

### 3. **TonalElevation** - Dark Theme
- Opacidades corretas: 0%, 5%, 8%, 11%, 12%, 14%
- Método `applyTonalElevation()` para aplicar overlay
- Suporte completo para Material You

### 4. **ElevationOverlay** - Overlay Colors
- Aplicação automática baseada no tema
- Conversão de elevação contínua para níveis discretos
- Métodos com e sem contexto

### 5. **ComponentElevation** - Valores Pré-definidos
- Elevações específicas para cada componente M3
- Estados (default, hover, pressed, etc.)
- Todos os valores alinhados com as specs oficiais

### 6. **Extras Adicionados**:

- **ElevationUtils**: Helpers para animações e transições
- **ElevatedSurface Widget**: Widget pronto para uso que combina sombras e tonal elevation
- Suporte completo para interpolação e animação
- Validação de valores
- Descrições human-readable

## 📊 Valores Exatos do M3

Os valores implementados correspondem exatamente às especificações:

- **Shadows**: Duas camadas com 30% e 15% de opacidade
- **Tonal Overlay**: 0%, 5%, 8%, 11%, 12%, 14% por nível
- **Component Values**: Todos alinhados com o Material Design 3

## 🚀 Exemplo de Uso

```dart
// Uso básico
Container(
  decoration: ElevationUtils.createElevatedDecoration(
    color: theme.colorScheme.surface,
    elevation: MaterialElevation.level2,
    borderRadius: BorderRadius.circular(12),
  ),
  child: content,
);

// Usando o widget helper
ElevatedSurface(
  elevation: ComponentElevation.cardElevated,
  borderRadius: BorderRadius.circular(12),
  padding: EdgeInsets.all(16),
  child: Text('Elevated Card'),
);

// Animação de elevação
AnimatedContainer(
  duration: MaterialDuration.short3,
  decoration: BoxDecoration(
    boxShadow: MaterialShadows.getShadows(
      isHovered ? 2 : 1,
    ),
  ),
);
```

O sistema está completo, type-safe, e 100% alinhado com as especificações do Material Design 3!
